📌 PROJECT DESCRIPTION

This is a full-stack Task Manager web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The application allows users to manage projects, assign tasks, and track progress with role-based access.

---

🚀 FEATURES

* User Authentication (Signup/Login using JWT)
* Project Management
* Task Creation and Assignment
* Task Status Tracking
* Dashboard Overview
* Team Management
* REST API Integration
* Fully Responsive UI

---

Frontend (.env):
REACT_APP_API_URL=https://taskmanager-92uu.onrender.com/api

---

▶️ HOW TO RUN LOCALLY

1. Clone the repository

2. Backend Setup:
   cd backend
   npm install
   npm run dev

3. Frontend Setup:
   cd frontend
   npm install
   npm start

📌 PROJECT OVERVIEW

The Task Manager Web Application is a full-stack web-based solution developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The primary goal of this application is to help users efficiently manage their daily tasks, organize projects, and collaborate with team members in a structured and user-friendly environment.

This system provides a centralized platform where users can create projects, assign tasks, monitor progress, and manage team activities. The application follows modern web development practices and includes secure authentication, responsive design, and scalable architecture.

---

🎯 OBJECTIVES OF THE PROJECT

* To design and develop a complete full-stack web application.
* To implement secure user authentication using JWT (JSON Web Tokens).
* To provide an efficient system for managing projects and tasks.
* To enable users to track task progress in real-time.
* To gain hands-on experience with modern technologies like React, Node.js, and MongoDB.
* To deploy a production-ready application accessible over the internet.

---

🚀 KEY FEATURES

1. User Authentication System:

   * Users can register and log in securely.
   * Passwords are encrypted using hashing techniques.
   * Authentication is handled using JWT tokens.

2. Project Management:

   * Users can create multiple projects.
   * Each project acts as a container for tasks.
   * Projects can be updated and managed easily.

3. Task Management:

   * Tasks can be created within projects.
   * Each task includes details such as title, description, and status.
   * Tasks can be updated, deleted, or marked as completed.

4. Dashboard:

   * Provides an overview of all tasks and projects.
   * Displays task status and progress.
   * Helps users quickly understand their workload.

5. Team Management:

   * Users can collaborate with team members.
   * Tasks can be assigned to different users.

6. RESTful API:

   * Backend provides structured API endpoints.
   * Enables smooth communication between frontend and backend.

7. Responsive Design:

   * Application works across devices (desktop, tablet, mobile).

⚙️ SYSTEM ARCHITECTURE

The application follows a client-server architecture:

* The frontend (React) handles user interaction and UI rendering.
* The backend (Node.js + Express) processes requests and handles business logic.
* MongoDB Atlas stores all application data such as users, projects, and tasks.
* REST APIs are used for communication between frontend and backend.

---

🔐 SECURITY FEATURES

* Passwords are securely hashed using bcrypt.
* JWT-based authentication ensures secure user sessions.
* Environment variables are used to protect sensitive information.
* API routes are protected and accessible only to authenticated users.

▶️ HOW TO RUN THE PROJECT LOCALLY

1. Clone the repository to your system.

2. Backend Setup:

   * Navigate to backend folder:
     cd backend
   * Install dependencies:
     npm install
   * Start the server:
     npm run dev

3. Frontend Setup:

   * Navigate to frontend folder:
     cd frontend
   * Install dependencies:
     npm install
   * Start the application:
     npm start

4. Open browser and access:
   http://localhost:3000
